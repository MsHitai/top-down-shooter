### **Right now the ETG fanfic is in very early stage of development.**

To load the game, first run the mvn clean package, then run AppLauncher.java from IDE or open the game via terminal, by
running this command:

java -jar game-0.0.1-SNAPSHOT.jar

**Plan of development:**

- Adding room generation, enemies, weapons and items
- Adding more options to the menu
- Adding pause and options to save or exit the game
- Adding a screen before the game starts to choose characters or challenges (after they are implemented)
- Adding more stages / rooms / secrets / etc.
- Adding different music, right now it uses music from ETG for testing purposes
