# ENTER THE FLUFFY

A top-down bullet-hell shooter in the spirit of *Enter the Gungeon*, written in Java with libGDX.

### How to run

First run `mvn clean package`, then run `AppLauncher.java` from the IDE, or start the game from a terminal:

    java -jar target/game-0.0.1-SNAPSHOT-jar-with-dependencies.jar

### How to play

Survive endless waves of bullet kin in a single room. Every 5th wave is a boss: **The Fluffy King**.

| Key | Action |
| --- | --- |
| WASD / arrows | move |
| Mouse | aim, hold left button to shoot |
| Space / right mouse / Left Shift | dodge roll (you're invincible during most of it) |
| Q | blank: clears every enemy bullet on screen and pushes enemies back |
| R | reload |
| Mouse wheel / E / Tab / 1-4 | switch gun |
| Esc / P | pause (restart, main menu, toggle music) |
| N | toggle music |

**Enemies**
- *Bullet Kin* - keeps its distance and fires single aimed shots (watch for the red glow on its gun).
- *Shotgun Kin* - slow and tanky, fires a fan of 5-7 bullets.
- *Bulletmancer* (wave 3+) - summons rings of bullets that start slow and speed up; some rings curve.
- *The Fluffy King* (every 5th wave) - rings, spirals and aimed fans; below half health it gets angry, faster, and calls for help.

**Guns** (earned by clearing waves 2, 3 and the first boss)
- *Rusty Sidearm* - starter, infinite ammo.
- *Fluff Shotgun* - 6 pellets, short range, big knockback.
- *Pocket Uzi* - very fast fire, low damage, wide spread.
- *Big Magnum* - slow, huge damage, bullets pierce through enemies.

**Pickups**: hearts (+1 heart), ammo boxes (refill limited guns), blanks. You get one after every wave, and enemies sometimes drop hearts or ammo. Your best score and best wave are saved.

### Dev shortcuts

Pass these as JVM options (e.g. in the IntelliJ run configuration, or `java -D... -jar ...`):

- `-Dfluffy.startWave=5` - start at a given wave (5 = first boss)
- `-Dfluffy.god=true` - hits never cost health
- `-Dfluffy.allGuns=true` - start with every gun

Sound effects in `assets/sfx/` are generated by `tools/gen_sfx.py` (needs `numpy`); tweak the recipes there and re-run it.
