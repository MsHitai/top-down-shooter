# AGENTS.md

## Project

Top-down bullet-hell shooter in the spirit of *Enter the Gungeon*, written in **Java 21** with **libGDX 1.13.5** (LWJGL3 desktop backend). Built with **Maven** (deliberately not Gradle — the owner knows Maven).

## Build & run

- Build: `mvn clean package`
- Run: `java -jar target/game-0.0.1-SNAPSHOT-jar-with-dependencies.jar` (the fat jar, not the thin one)
- Run from IDE: `com.trush.game.launcher.AppLauncher`
- Debug flags only work in a **dev build**: `mvn clean package -Pdev` (Maven filters `src/main/resources/dev.properties`; running from the IDE without filtering also counts as dev). A normal `mvn clean package` ignores them all. Flags (see `launcher/Dev`): `-Dfluffy.god=true`, `-Dfluffy.allGuns=true`, `-Dfluffy.bossRoom=true` (a new story run from the menu starts at the boss), `-Dfluffy.retryBoss=true` (try again/restart goes back to the boss instead of floor 1), `-Dfluffy.keepSave=true` (continuing doesn't use up the save), `-Dfluffy.boss=haymaker` (force a boss), `-Dfluffy.floor=N` (start a story run on floor N; 2 = the town), `-Dfluffy.startWave=N` and `-Dfluffy.layout=N` (endless). Read new flags through `Dev.flag`/`Dev.number`, never `System.getProperty`. Only `dev.properties` is filtered — never filter binary assets.

## Code map

- `launcher/ETGFanfic` — the `Game`; owns shared `batch`, `font`, `viewport`, `draw` (`gfx/Draw`), `sprites` (`gfx/Sprites`), `sfx` (`audio/Sfx`), `prefs` (best score/wave). Use `game.text(str, x, y, scale, color, Align.x)` for text.
- `screen/MainMenuScreen` (mode select), `screen/GameScreen` (story or endless) — input states (playing / paused / game over / stage clear), camera shake, music crossfades, HUD + minimap. All simulation lives in `world/GameWorld`.
- `save/RunSave` — between-floors save, like ETG: only offered on the stage clear screen after the boss (or when the window is closed there). Holds next floor number, score/kills, hearts, blanks, guns + ammo (by name via `Weapon.byName` — register new guns there). Continue starts `StoryDirector(floor, ownedGuns)` on that floor's `Stage` (+0.15 difficulty per floor). Deleted when continued or when a new run starts. No saving mid-floor.
- Map: the HUD minimap and the big map (hold LT on the pad / M on the keyboard; the world pauses) share `GameScreen.drawRooms`, which also shows what's left in visited rooms (unopened chests as little chest shapes in tier colours, keys as yellow key shapes, every other item as an orange dot, the open exit in green). On the big map the player picks a visited room (stick / d-pad / arrows / mouse) and teleports there with A / Enter / click (`GameWorld.teleportTo`; not while the room is locked for a fight).
- `screen/MenuList` — shared mouse/keyboard/gamepad text menu (main menu, pause menu).
- `world/GameWorld` — the current `Room` and everything in it: player, enemies, bullets, pickups (stored on the room), particles; collisions vs walls/props, table flipping, blanks, room transitions through doors.
- `world/Director` — game-mode interface. `StoryDirector` (story floors: lock doors, spawn the stage's enemies, rewards, boss, `isFinished`) and `WaveDirector` (endless waves).
- `world/Stage` — a story stage: VILLAGE (floor 1), TOWN (floor 2), CITY (floor 3, at night; later floors replay the last stage, harder). Name, music + boss music, room themes, layout-letter → furniture (town: benches for hay, lamps for pillars; city: parked cars and lamps), door `Barricade` (planks / road barriers / police tape), pit chance, `night` (GameWorld.drawNight: a darkness vignette around the player, lamps cast additive light, bullets drawn on top), clear-screen text.
- Pits (town): `Room.pits` are 1x1 open hatches (`Stage.pitChance` of combat/arena rooms get 1–2, away from doors, furniture and the room centre). Player falls if they stop on one (rolling over is fine): `Player.startFall` → `GameWorld.onPlayerFell` puts them back at the last safe spot for half a heart. Walking enemies are kept off the edge unless a bullet's knockback is shoving them (`Enemy.knockSpeed`); falling in kills them. Bosses/flyers ignore pits. `pointIsFree` treats pits as blocked (nav, spawns, chests, pickups).
- `world/StageMap` — random tree of rooms on a grid (start, combat, treasure, boss), themed by its `Stage`. Room sizes: start/treasure 13x8 (one screen), combat 19x12 (camera scrolls) or 30% small 13x8 "trap" rooms (town: 3-4 pits), boss arenas 25x15 - `RoomTemplates.BOSS_OPEN`, or `BOSS_COVER` (pillars/lamps) for bosses with `Boss.cover` (Hollow Witch, Road Rager). 13x8 combat layouts are centred in bigger rooms (`Room.build`). The enemy nav grid is sized per room. `world/Room` — doors, lock state, props, wall collision rects. `world/RoomTemplates` — 8x13 layout strings. `world/Arena` — per-room geometry (see World below).
- `gfx/RoomRenderer` — bakes a room's floor/walls/doors from `assets/tiles/<theme>.png` (10 tiles: 4 floors, wall face, cap, door frame, unused, face+window, face+decoration) into one texture; draws a plank barricade over doors when locked.
- `input/Gamepad` — Xbox-layout gamepad (gdx-controllers + Jamepad), polled once per frame in `ETGFanfic.render()`; `game.pad.justPressed(Button.X)`, sticks, `isActive()` (pad vs mouse used last). Hold Y opens the gun wheel in `GameScreen`.
- `player/Player` — movement with feet-box collision, dodge roll (rolls pass over standing tables via `GameWorld.findSolid(r, true)`, knocking each table once per roll with `rollOverTables`; a roll never ends on a table), `E` flip, weapons inventory, hearts (half-hearts; `HEART_CONTAINER` pickups add a max heart up to `Player.MAX_HEALTH_CAP` = 8 hearts - dropped by a boss beaten without a single hit (`GameWorld.bossFlawless`, like ETG's Master Round) and sometimes in gunless chests, better odds in better chests; the HUD wraps hearts in rows of 4), blanks; animated pixel sprite + floating gun hand.
- `objects/Chest` + `objects/Tier` — ETG-style loot: chests per tier (D brown, C blue, B green, A red); a chest holds the not-yet-owned gun of its tier (reserved from `StoryDirector`'s pool when the chest is placed) or else consumables. Locked chests cost a key (`Player.keys`, saved between floors); the boss chest is free. Story mode only hands out guns via chests: treasure room (locked), rare locked room-reward chest, boss chest. One guaranteed key per floor (cleared combat room #1–3), extra keys are rare drops. After the boss, `GameWorld.openExit()` shows a floor hatch; interacting on it (`GameWorld.interact`: chest > exit > flip table) ends the floor. Give every new gun a `tier`.
- `objects/Weapon` (add guns as static factories; each names a `sprite` in `assets/sprites/guns.png`/`guns.txt`, generated by `tools/gen_sprites.py` GUN_SPRITES - pointing right, held at a grip pixel whose row is the barrel row; `Sprites.GunSprite.drawHeld/drawIcon`, muzzle = grip + `length()`). Guns: Rusty Sidearm (starter); chest guns via `Weapon.chestGuns()` (two per tier): D Confetti Popper, Bubble Blaster; C Fluff Shotgun, Banana-rang (a real boomerang: `Bullet.boomerang`, out and back to the hand in `GameWorld.updateBoomerang`); B Pocket Uzi, Bee Hive; A Big Magnum, Rainbow Ray. Bullet extras: `curve`, `wobble`, `homing` (player bullets steer in `GameWorld.steerToNearestEnemy`), `bubble` look; `Weapon.ColorMode` RAINBOW/CONFETTI colours each bullet., `objects/Bullet` (`accel`, `curve` for patterns), `objects/Pickup`, `objects/Prop` (furniture: tables flip, most props destructible).
- `enemy/Enemy` — base class; behind cover, `keepDistance` paths around props to a spot with line of sight (`GameWorld.hasLineOfSight` / `findSightPoint`, a 0.25-unit nav grid) and enemies only start attacks when they can see the player and are on screen (`Enemy.canShoot`, `GameWorld.onScreen`); `BulletKin`, `ShotgunKin`, `Bulletmancer` (village); `Hydrant` (stationary sweeping spray), `Rat` (quick melee packs of 3; `squishable`: a dodge roll over them kills them), `ShellCop` (3-round bursts that lead the target) (town, also endless from wave 3-6); `Biker` (circles the player on a motorcycle, drive-by streams), `Sniper` (laser sight tracks, locks, one fast shot; the laser stops at cover) (city, endless from wave 6-7); bosses `FluffyKing` (rings/spirals/fans), `Haymaker` (charges, straw walls, crows, hay rain) `Harvestman` (stalks you with a chainsaw: exhaust sprays, homing lunges with sawdust, boomerang blades) and `HollowWitch` (flies over furniture via `Enemy.flying`: curving hex bolts, swoops leaving delayed sparks, closing hex ring with one gap, jack-o'-lanterns that burst); town: `TrashThatCan` (designed by the owner's son: hops; garbage bombs that burst when they hit something, gapless trash walls and a wavy diagonal line you must roll over) and `RoadRager` (son's monster truck: roof cannon, sweeping twin headlight lasers via `GameWorld.rayLength`/`hurtPlayer`, throws enemies from the roof hatch, rams across the room) and `TrafficLight` ("Red Light, Green Light": green streams, yellow warning, red freezes every bullet and punishes moving, then bursts them outward); city: `NightHawk` (flying helicopter: door gun, strafing runs, rocket fans that burst, a searchlight that chases the player then blows up its spot) and `PigeonKing` (arena theme "plaza" via `Boss.arenaTheme()`; perched on a `PEDESTAL` prop near the arena centre, added via `GameWorld.addProp`: flock lines from the walls with gaps, breadcrumbs that become pecking pigeons, curving feather fans; enraged it flies off the statue) and `EvilTrain` (son's design: runs only on an oval loop it draws via `Enemy.drawFloor`, wagons hurt too, smokestack puffs harmful smoke upward, coal + wagon volleys, whistle + charge lap, brake + steam ring + reverse; arena theme "railyard"), listed in `enemy/Boss` — each boss belongs to a `Stage` and a story floor rolls one of its stage's bosses (`Boss.pickFor(stage)`); the Fluffy King is the final boss (`stage == null`), so until the last floor exists he only appears in endless boss waves (`Boss.pickAny()`). `Boss.byName` matches dev-flag names forgivingly; each boss has a `defeated` banner line. Bosses use `Enemy.huntForSight` to come out from behind cover and override `bossName()`/`isEnraged()` for the boss bar.

## Conventions

- Plain Maven project — **no Spring Boot**; keep it out of the POM.
- Test dependencies (JUnit, Mockito, Hamcrest) stay at `test` scope.
- The LWJGL3 backend extracts natives automatically — do not re-add `maven-nativedependencies-plugin` or `antrun` launch hacks (those were LWJGL2-era workarounds).
- Assets live under `src/main/resources/assets/` and are loaded with the `assets/` prefix, e.g. `new Texture("assets/player.png")`. Do not flatten assets into the classpath root.
- The shared font (`ETGFanfic.font`) is a FreeType-generated pixel font (Press Start 2P, Latin-only — no `∞` etc.) created once in `ETGFanfic.create()` and disposed in `ETGFanfic.dispose()`. Screens must use it, not create/dispose their own.
- Never call `setUseIntegerPositions(true)` on fonts — the world is only 7×5 units and rounding to integer positions collapses small text to nothing.
- World: `FitViewport(7, 5)` - the camera shows 7x5 units (`Arena.VIEW_W/H`); pixel art is 32 px per unit. Each room has its own geometry (`Room.arena`, an `Arena(cols, rows)`: walls, door gaps, layout grid; 13x8 = one screen); gameplay code uses the current room's `Arena.now` (set in `GameWorld.enterRoom`), code that builds/draws a specific room uses `room.arena`. `GameScreen.updateCamera` follows the player and leans toward the aim (and toward the boss in boss fights, always keeping the player well in view), clamped to the room (black beyond the walls); the HUD is drawn with a fixed camera in 7x5 screen units, world-space overlays (prompts, pad reticle) in `drawWorldOverlays`.
- Art is generated: `tools/gen_sprites.py` (hero, props + `props.txt` atlas, tilesets), `tools/gen_sfx.py`, `tools/music/tracks.py` (FluidSynth + GeneralUser GS soundfont from the Towards Dreams project; tracks: menu, village, town, city, boss (the Fluffy King's theme), boss_village, boss_town, boss_city - `Stage.bossMusic`, `Boss.music()`; falls back to ffmpeg's built-in vorbis encoder when libvorbis is missing). Edit the scripts and regenerate rather than hand-editing the PNG/WAV/OGG files. Use Nearest filtering for pixel art.
- The player collides with a small feet box (`Player.feetRect`), not the sprite; enemies are circles pushed out of walls/props (`GameWorld.pushOutOfSolids`).
- Enemies, bullets, guns and pickups are still placeholder art drawn with `gfx/Draw` (shapes on the SpriteBatch, no ShapeRenderer). Replace a `drawBody` with sprites when real art exists; keep hitboxes (`radius`) independent of art.
- Bullets (and enemy line of sight, lasers) are stopped by `Prop.bulletRect(sprites, northbound)`: a bullet going up the screen hits the whole tall part (up to just below the sprite top, so standing behind a pillar covers you); going down or sideways it only hits the footprint. Street lamps block with a slim 0.14 post and are breakable (30 hp). Bullets touching the player's visible body only break on it when cover is really between them (`GameWorld.coverBetween`) - never all-round immunity. Movement still uses the footprint (`solid`). Tests that mock libGDX classes need `MockMakers.SUBCLASS` (inline mocking fails on newer JDKs).
- Boss bullets: everything a boss fires during its `behave` is restyled by `GameWorld.styleBossBullets` - 1.3x bigger and 0.85x slower, with `Bullet.hitScale` keeping the hitbox the same size (patterns read better, gaps don't shrink). Regular enemies' bullets are unchanged.
- Collisions are circle-vs-circle. The player's hitbox is a small circle around the belly (`Player.hitboxY()`, `HITBOX_RADIUS`), not the sprite rectangle.
- Don't remove from `enemyBullets` while it may be iterated — mark `alive = false` and let `GameWorld` sweep (taking damage and blanks clear bullets mid-update).
- Spawn enemies via `GameWorld.spawnEnemy` (goes through a pending list), never by adding to `enemies` directly during update.
- Sound effects: `assets/sfx/*.wav` are generated by `tools/gen_sfx.py`; register new ones in `audio/Sfx`. `sfx/death.wav` is `assets/die-sound.mp3` with its leading silence cut (needs ffmpeg), so it lines up with the death animation; `body_fall` plays when the hero hits the floor. Regenerating rewrites every WAV — only commit the ones whose audio actually changed.
- Lombok (`@Getter`, `@Data`) is used; keep the annotation processor path in `maven-compiler-plugin`.
- `listener/DropListener.java` and `listener/FluffyListener.java` are leftover libGDX tutorial code, candidates for deletion. `objects/Coin.java` and `objects/Table.java` are unused stubs referencing textures that don't exist yet.
- Commit and push after every finished change (once it builds and tests pass): one change per commit, with a sensible conventional message (`feat: ...`, `fix: ...`), then `git push`. Don't leave work uncommitted.
- Commit with `git -c core.autocrlf=input` from Linux shells: some older files have CRLF line endings on disk and the owner's Mac git normalizes them.
- `assets/floor.png`, `assets/player.png` and the ETG `.mp3` tracks are no longer used by the game.
