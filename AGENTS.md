# AGENTS.md

## Project

Top-down bullet-hell shooter in the spirit of *Enter the Gungeon*, written in **Java 21** with **libGDX 1.13.5** (LWJGL3 desktop backend). Built with **Maven** (deliberately not Gradle — the owner knows Maven).

## Build & run

- Build: `mvn clean package`
- Run: `java -jar target/game-0.7.0-SNAPSHOT-jar-with-dependencies.jar` (the fat jar, not the thin one)
- Run from IDE: `com.trush.game.launcher.AppLauncher`
- Debug flags only work in a **dev build**: `mvn clean package -Pdev` (Maven filters `src/main/resources/dev.properties`; running from the IDE without filtering also counts as dev). A normal `mvn clean package` ignores them all. Flags (see `launcher/Dev`): `-Dfluffy.god=true`, `-Dfluffy.allGuns=true`, `-Dfluffy.items=all` (or `fluff_field,grenade`), `-Dfluffy.bossRoom=true` (a new story run from the menu starts at the boss), `-Dfluffy.retryBoss=true` (try again/restart goes back to the boss instead of floor 1), `-Dfluffy.keepSave=true` (continuing doesn't use up the save), `-Dfluffy.boss=haymaker` (force a boss), `-Dfluffy.floor=N` (start a story run on floor N; 2 = the town), `-Dfluffy.mimic=true` (every town/city combat room hides a mimic lamp), `-Dfluffy.play=story` / `endless` (skip the main menu - handy for trying a floor: `-Dfluffy.play=story -Dfluffy.floor=5`), `-Dfluffy.startWave=N` and `-Dfluffy.layout=N` (endless), `-Dfluffy.shop=true` (a story run starts in the shop; endless opens the travelling stall before wave 1), `-Dfluffy.coins=N` (start with N coins). Read new flags through `Dev.flag`/`Dev.number`, never `System.getProperty`. Only `dev.properties` is filtered — never filter binary assets.

## Code map

- `launcher/ETGFanfic` — the `Game`; owns shared `batch`, `font`, `viewport`, `draw` (`gfx/Draw`), `sprites` (`gfx/Sprites`), `sfx` (`audio/Sfx`), `prefs` (best score/wave). Use `game.text(str, x, y, scale, color, Align.x)` for text.
- `screen/MainMenuScreen` (mode select), `screen/GameScreen` (story or endless) — input states (playing / paused / game over / stage clear / victory - beating the boss of `Stage.lastFloor()` wins the run: confetti, score, `ETGFanfic.getWins()`, play again or menu; no save), camera shake (and zoom: a boss's `Enemy.viewZoom`), music crossfades, HUD + minimap; world overlays over the hero: RELOAD (magazine nearly empty, `Weapon.wantsReload`) / EMPTY hints and the Long Shot's laser sight; when every enemy left in a fight has been off screen for `LOST_DELAY` 1.2 s, red arrows at the screen edge point at each one (`updateLostEnemies`/`drawEnemyArrows`). When a boss appears (`activeBoss`, once per spawn) `screen/BossCard` shows an ETG-style introduction while the world holds still: a tilted band, a close-up via `Enemy.drawPortrait` (a fresh `Boss.create` instance; the Kaiju overrides it to draw just its head), "THE" + the name, and its line `Boss.quote()` typed out under it; any key / click / A / B skips (Esc too, instead of pausing). The victory screen shows `screen/EndingPicture` (picture-book style: the restored kingdom, the castle back on its cloud, the hero flying off on a cloud with a rainbow trail). All simulation lives in `world/GameWorld`.
- `save/RunSave` — between-floors save, like ETG: only offered on the stage clear screen after the boss (or when the window is closed there). Holds next floor number, score/kills, hearts, blanks, keys, coins, Baa-llo's grudge, guns + ammo (by name via `Weapon.byName` — register new guns there). Continue starts `StoryDirector(floor, ownedGuns)` on that floor's `Stage` (+0.15 difficulty and +25% regular-enemy health per floor via `GameWorld.setEnemyHealth`, applied in `spawnEnemy`; endless +4% health a wave up to +75%; bosses scale by their tier instead). Deleted when continued or when a new run starts. No saving mid-floor.
- Map: the HUD minimap and the big map (hold LT on the pad / M on the keyboard; the world pauses) share `GameScreen.drawRooms`, which also shows what's left in visited rooms (unopened chests as little chest shapes in tier colours, keys as yellow key shapes, every other item as an orange dot, the open exit in green). On the big map the player picks a visited room (stick / d-pad / arrows / mouse) and teleports there with A / Enter / click (`GameWorld.teleportTo`; not while the room is locked for a fight). The big map doesn't open during a fight (`Director.inFight`: a locked room / an endless wave) - a stray LT would hide the bullets.
- `screen/IntroScreen` — the opening story, a picture book of six pages (typewriter text under scenes drawn from the game's own art via `Enemy.drawPortrait`, hero/prop/gun sprites); plays before the first story run (prefs `seenIntro`), "THE STORY" in the main menu replays it; any key/click/A turns the page, Esc/B/Start skips.
- `screen/MenuList` — shared mouse/keyboard/gamepad text menu (main menu, pause menu).
- `world/GameWorld` — the current `Room` and everything in it: player, enemies, bullets, pickups (stored on the room), particles; collisions vs walls/props, table flipping, blanks, room transitions through doors.
- `world/Director` — game-mode interface. `StoryDirector` (story floors: lock doors, spawn the stage's enemies, rewards, boss, `isFinished`) and `WaveDirector` (endless waves).
- `world/Stage` — a story stage: VILLAGE (floor 1), TOWN (floor 2), CITY (floor 3, at night), SKYSCRAPER (floor 4, by day), CLOUDS ("THE FLUFFY KINGDOM", floor 5; beating its boss - always the Fluffy King, `Boss.pickFor` gives the last stage the final boss - wins the run: the victory always sits on `Stage.lastFloor()`). The clouds (`Stage.isSky()`, `Room.openSky()` - also true for the roof theme): see-through caps (cap kind "open" in gen_sprites) so `GameWorld.drawSky` shows behind every room (darker for the "storm" theme), `RoomRenderer.paintCloudRim` puffs the floor's edges out into the sky, the camera may look 1.5 past the side edges; themes cloudgate (start, pearly gates), clouds, temple, storm, rainbow (treasure), throne (boss, `paintCarpet`); furniture: cloud banks for hay (`Prop.Kind.CLOUD`), marble columns for pillars (unbreakable), golden urns for barrels, presents for crates; doors get cloud plugs (`Barricade.CLOUD`); pits are holes in the clouds (`Stage.pitSprite()` "pit_sky", `pitChance` 0.4); the exit is a rainbow (`Exit.RAINBOW`, "SLIDE HOME"); layout tables (`T`) become cloud banks too - no tables up there. Birds (the owner's idea, `objects/Bird`, `GameWorld.updateBirds`): during a fight in a cloud combat room / endless cloud arena, every 3.5-6 s a bird or a flock of three flies across at about the player's height after a `WARN_TIME` 0.9 s white arrow at the edge; touching one goes through `hurtPlayer`, bullets ignore them, they vanish off the far edge. The skyscraper (`Stage.isTower()`) is a straight climb: `StageMap.buildTower` stacks the lobby, 5-7 elevator stops (one a treasure floor) and the roof (boss) going north, each `Room.floorNumber` 5-10 storeys above the last; going through a door between storeys runs `GameWorld`'s elevator ride (`ELEVATOR_TIME`, the world waits; `GameScreen.drawElevator` shows shut doors and the storey counter), and the room greets you with "FLOOR 23". Its themes: lobby, office, servers, cafeteria, vault (treasure), roof (boss: daytime parapet with sky); furniture: desks for hay, potted plants for pillars, water coolers for barrels; locked doors get steel shutters (`Barricade.SHUTTER`). Name, music + boss music, room themes, layout-letter → furniture (town: benches for hay, lamps for pillars; city: parked cars and lamps), door `Barricade` (planks / road barriers / police tape), pit chance, `night` (GameWorld.drawNight: a darkness vignette around the player, lamps cast additive light, bullets drawn on top), clear-screen text.
- Pits (town, clouds): `Room.pits` are 1x1 open hatches (holes in the clouds on floor 5) (`Stage.pitChance` of combat/arena rooms get 1–2, away from doors, furniture and the room centre). Player falls if they stop on one (rolling over is fine): `Player.startFall` → `GameWorld.onPlayerFell` puts them back at the last safe spot for half a heart. Walking enemies are kept off the edge unless a bullet's knockback is shoving them (`Enemy.knockSpeed`); falling in kills them. Bosses/flyers ignore pits. `pointIsFree` treats pits as blocked (nav, spawns, chests, pickups).
- `world/StageMap` — random tree of rooms on a grid (start, combat, treasure, boss), themed by its `Stage` (the skyscraper is a straight stack instead, `buildTower`). Room sizes: start/treasure 13x8 (one screen), combat 19x12 (camera scrolls) or 30% small 13x8 "trap" rooms (town: 3-4 pits), boss arenas 25x15 - `RoomTemplates.BOSS_OPEN`, or `BOSS_COVER` (pillars/lamps) for bosses with `Boss.cover` (Hollow Witch, Road Rager), or `BOSS_CARS` (three parked cars, layout letter `K`) for the Traffic Light - picked by `Boss.arenaLayout()`. 13x8 combat layouts are centred in bigger rooms (`Room.build`). The enemy nav grid is sized per room. `world/Room` — doors, lock state, props, wall collision rects. `world/RoomTemplates` — 8x13 layout strings. `world/Arena` — per-room geometry (see World below).
- `gfx/RoomRenderer` — bakes a room's floor/walls/doors from `assets/tiles/<theme>.png` (10 tiles: 4 floors, wall face, cap, door frame, unused, face+window, face+decoration) into one texture; draws a plank barricade over doors when locked.
- `input/Gamepad` — Xbox-layout gamepad (gdx-controllers + Jamepad), polled once per frame in `ETGFanfic.render()`; `game.pad.justPressed(Button.X)`, sticks, `isActive()` (pad vs mouse used last). Hold Y opens the gun wheel in `GameScreen`.
- `player/Player` — movement with feet-box collision, dodge roll (rolls pass over standing tables via `GameWorld.findSolid(r, true)`, knocking each table once per roll with `rollOverTables`; a roll never ends on a table), `E` flip (F now uses the active item), weapons inventory, hearts (half-hearts; `HEART_CONTAINER` pickups add a max heart up to `Player.MAX_HEALTH_CAP` = 16 hearts (the first 8 red - `RED_HEARTS`; hearts 9-16 are golden, drawn layered over the red ones: a golden rim peeks out behind each red heart that has a golden container, gold covers it while filled; hits take the golden ones first) - dropped by a boss beaten without a single hit (`GameWorld.bossFlawless`, like ETG's Master Round) and sometimes in gunless chests, better odds in better chests; the HUD wraps the red hearts in two rows of 4), blanks; animated pixel sprite + floating gun hand.
- `objects/Chest` + `objects/Tier` — ETG-style loot: chests per tier (D brown, C blue, B green, A red); a chest holds the not-yet-owned gun of its tier (reserved from `StoryDirector`'s pool when the chest is placed) or else consumables. Locked chests cost a key (`Player.keys`, saved between floors); the boss chest is free. Story mode only hands out guns via chests: treasure room (locked), rare locked room-reward chest, boss chest. One guaranteed key per floor (cleared combat room #1–3), extra keys are rare drops. After the boss, `GameWorld.openExit()` shows the stage's way on (`Stage.exit`: the village a gate to the town road, the town a bus stop, the city the skyscraper doors, the skyscraper a helicopter; sprites `exit_*` in props.txt, drawn standing up from the spot you use it on, with its own prompt); interacting on it (`GameWorld.interact`: chest > exit > flip table) ends the floor. Give every new gun a `tier`. Finding a gun you already carry (dev `allGuns`, endless rewards) doesn't add a second copy: `Player.addWeapon` gives the owned one a random `Weapon.Upgrade` (+15% damage, +25% magazine/ammo, or +15% bullet speed), refills it, and it shows as "Name +N" (`displayName`); upgrades are saved in `RunSave.GunData.upgrades`.
- Coins and the shop: `objects/Coins` (the numbers: enemies drop score/20 coins on average via `Coins.forEnemy` - none for a boss's minions while the boss lives; cleared rooms 3-5 + depth/2; bosses 20 + 5 per floor; chests without a gun/item 3-11; endless waves 2 + wave/3; big coins worth `BIG` 5 for most of a large amount) spilled by `GameWorld.dropCoins` as `Pickup.coin` (spinning `coin_0..3` / `coin_big` in props.txt, picked up from `COIN_REACH`; once a fight is over - `GameWorld.calm` past `COIN_RUSH_DELAY` - every coin in the room flies to the player, like ETG's casings), kept in `Player.coins` (cap `Coins.MAX`), HUD next to the keys. `objects/Shop` is Baa-llo's shop (the owner's pick: a sheep, our Bello): `Shop.price` (D/C/B/A 25/45/70/100, heart/blank 15, ammo 20, key 30; +10% a level = story floor / endless bosses beaten; sale -25%; grudge +50%), `stock` takes two wares (gun or item per rolled tier, nearest tier if empty; on floor 1 the first is always a tier D gun - `gunFirst`, the owner's call, so floor 1 always offers a gun) out of the director's pools and adds heart, blank-or-ammo, key, one slot on sale; the keeper's lines, ducking and grudge (`GRUDGE_HITS` 3 - shooting him is ETG's Bello grudge, the owner's choice; `GameWorld.shopGrudge`, saved in `RunSave`). Every story map has a `Room.Type.SHOP` dead end (`StageMap.addShop`, never entered from the north; the skyscraper makes one stop a shop), themed `Stage.shopTheme` (store_village/town/city/tower/sky tilesets, face kind "store"); `StoryDirector` stocks it on first entry and `GameWorld.openShop` puts the counter (`Prop.Kind.COUNTER`/`CLOUD_COUNTER`) against the top wall with the sheep behind it and five `STAND`s in a row - shop furniture doesn't block bullets, so they fly over the counter at him (`hitShopkeeper`). Interact buys (`GameWorld.buy`, chest > stand > bell > exit > table; refuses a heart at full health etc.); the bought pickup goes through `collect`. GameScreen draws his speech bubble beside his head and a coin on the map. Endless: `WaveDirector.State.SHOP` after each boss wave - a travelling stall (`Shop.travelling`, clears furniture in its way) until the player rings the bell (`atTheBell` → `bellRung` → `closeShop`).

A chest holds a gun or an item of its tier (`StoryDirector.chest`, 50/50 when both are left; each item once per run, saved by name in `RunSave`); endless boss waves drop one. ## Conventions

- Plain Maven project — **no Spring Boot**; keep it out of the POM.
- Test dependencies (JUnit, Mockito, Hamcrest) stay at `test` scope.
- The LWJGL3 backend extracts natives automatically — do not re-add `maven-nativedependencies-plugin` or `antrun` launch hacks (those were LWJGL2-era workarounds).
- Assets live under `src/main/resources/assets/` and are loaded with the `assets/` prefix, e.g. `new Texture("assets/player.png")`. Do not flatten assets into the classpath root.
- The shared font (`ETGFanfic.font`) is a FreeType-generated pixel font (Press Start 2P, Latin-only — no `∞` etc.) created once in `ETGFanfic.create()` and disposed in `ETGFanfic.dispose()`. Screens must use it, not create/dispose their own.
- Never call `setUseIntegerPositions(true)` on fonts — the world is only 7×5 units and rounding to integer positions collapses small text to nothing.
- World: `FitViewport(7, 5)` - the camera shows 7x5 units (`Arena.VIEW_W/H`); pixel art is 32 px per unit. Each room has its own geometry (`Room.arena`, an `Arena(cols, rows)`: walls, door gaps, layout grid; 13x8 = one screen); gameplay code uses the current room's `Arena.now` (set in `GameWorld.enterRoom`), code that builds/draws a specific room uses `room.arena`. `GameScreen.updateCamera` follows the player and leans toward the aim (and toward the boss in boss fights, always keeping the player well in view), clamped to the room (black beyond the walls); the HUD is drawn with a fixed camera in 7x5 screen units, world-space overlays (prompts, pad reticle) in `drawWorldOverlays`.
- Art is generated: `tools/gen_sprites.py` (hero, props + `props.txt` atlas, tilesets), `tools/gen_sfx.py`, `tools/music/tracks.py` (FluidSynth + GeneralUser GS soundfont from the Towards Dreams project; tracks: menu, village, town, city (room themes get darker floor by floor: folk-rock village, harmonic-minor galloping town, cold synth city with a tolling bell; endless switches village → town → city → tower → sky at waves 6, 11, 16 and 21), boss (the Fluffy King's theme), boss_village, boss_town, boss_city, tower (lift-music intro, then office rock), boss_tower (orchestral, on the roof), sky ("Silver Lining", the clouds: harp, celesta, choir, then the band; their boss is the Fluffy King, so the boss track is his "boss") - `Stage.bossMusic`, `Boss.music()`; falls back to ffmpeg's built-in vorbis encoder when libvorbis is missing). Edit the scripts and regenerate rather than hand-editing the PNG/WAV/OGG files. Use Nearest filtering for pixel art.
- The player collides with a small feet box (`Player.feetRect`), not the sprite; enemies are circles pushed out of walls/props (`GameWorld.pushOutOfSolids`).
- Enemies, bullets, guns and pickups are still placeholder art drawn with `gfx/Draw` (shapes on the SpriteBatch, no ShapeRenderer). Replace a `drawBody` with sprites when real art exists; keep hitboxes (`radius`) independent of art.
- Bullets (and enemy line of sight, lasers) are stopped by `Prop.bulletRect(sprites, northbound)`: a bullet going up the screen hits the whole tall part (up to just below the sprite top, so standing behind a pillar covers you); going down or sideways it only hits the footprint. Street lamps block with a slim 0.14 post and are breakable (30 hp). Bullets touching the player's visible body only break on it when cover is really between them (`GameWorld.coverBetween`) - never all-round immunity. Movement still uses the footprint (`solid`). Tests that mock libGDX classes need `MockMakers.SUBCLASS` (inline mocking fails on newer JDKs).
- Boss bullets: everything a boss fires during its `behave` is restyled by `GameWorld.styleBossBullets` - 1.3x bigger and 0.85x slower, with `Bullet.hitScale` keeping the hitbox the same size (patterns read better, gaps don't shrink). Regular enemies' bullets are unchanged.
- Collisions are circle-vs-circle. The player's hitbox is a small circle around the belly (`Player.hitboxY()`, `HITBOX_RADIUS`), not the sprite rectangle.
- Don't remove from `enemyBullets` while it may be iterated — mark `alive = false` and let `GameWorld` sweep (taking damage and blanks clear bullets mid-update).
- Killed enemies move from `enemies` to `GameWorld.dying` and play their death there (`Enemy.updateDeath`/`drawDying`: regular ones topple away from the shot and shrink, pit fallers spin down, bosses get slow motion, ~2 s of explosions and a big blast); the room only clears when `GameWorld.bossDying()` is false. Code that needs a boss gone (rewards) waits for that.
- Spawn enemies via `GameWorld.spawnEnemy` (goes through a pending list), never by adding to `enemies` directly during update.
- Sound effects: `assets/sfx/*.wav` are generated by `tools/gen_sfx.py`; register new ones in `audio/Sfx` (the angels use `swish` / `twang`, birds `flap`, coins `coin`, the shop `kaching` and Baa-llo `baa`; `whistle` is the Evil Train's). `sfx/death.wav` is `assets/die-sound.mp3` with its leading silence cut (needs ffmpeg), so it lines up with the death animation; `body_fall` plays when the hero hits the floor. Regenerating rewrites every WAV — only commit the ones whose audio actually changed.
- Lombok (`@Getter`, `@Data`) is used; keep the annotation processor path in `maven-compiler-plugin`.
- `listener/DropListener.java` and `listener/FluffyListener.java` are leftover libGDX tutorial code, candidates for deletion. `objects/Coin.java` and `objects/Table.java` are unused stubs referencing textures that don't exist yet.
- Commit and push after every finished change (once it builds and tests pass): one change per commit, with a sensible conventional message (`feat: ...`, `fix: ...`), then `git push`. Don't leave work uncommitted.
- Commit with `git -c core.autocrlf=input` from Linux shells: some older files have CRLF line endings on disk and the owner's Mac git normalizes them.
- `assets/floor.png`, `assets/player.png` and the ETG `.mp3` tracks are no longer used by the game.
